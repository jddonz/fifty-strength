# Fifty Strength

A small, privacy-first workout PWA for the 8-week strength + CrossFit foundation program.

## Development

The app is a static web application designed for GitHub Pages. Workout history, weights, reps, RPE, and knee tracking are stored locally in the browser; no personal workout data is sent to a server.

## Security principles

- No secrets or credentials in the repository.
- Minimal GitHub Actions permissions.
- No third-party runtime JavaScript dependencies.
- Local-only workout data storage.
- Accessible, mobile-first UI.
